# مشروع بناء تطبيق أندرويد

هذا المستودع يقوم بتحويل كود HTML إلى تطبيق أندرويد (APK) تلقائياً باستخدام GitHub Actions.

## كيف أبني التطبيق؟
1. اذهب إلى تبويب **Actions** في الأعلى.
2. اختر **Build Android APK** من القائمة اليسرى.
3. اضغط على زر **Run workflow** ثم اضغط الزر الأخضر مرة أخرى.
4. انتظر بضع دقائق حتى يخلص البناء.
5. انزل لأسفل الصفحة، ستجد ملف APK جاهز للتحميل في قسم **Artifacts**.
